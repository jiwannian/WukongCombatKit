# WukongCombatKit 设计文档

日期：2026-08-17  
游戏：黑神话：悟空  
加载器：B1CSharpLoader + Harmony  
范围：独立单机 C# Mod，不修改现有 AutoPerfectDodge

## 1. 目标

玩家手动操作时获得两项战斗手感调整：

1. **普攻可空格闪避打断**：按下空格时，如果当前动作是轻攻/普通棍法连招，允许闪避打断该普攻。不自动闪避，不强制完美闪避。
2. **无遮挡全方位几乎无限距离攻击**：玩家所有攻击（普攻、技能、蓄力、棍势等）可以打中以自身为中心、四面八方、几乎无限距离、且墙壁/地形未遮挡的敌人。

明确不做：

- 不自动闪避
- 不把普通闪避改成完美闪避
- 不打断技能、蓄力、释放棍势、变身等非普攻动作
- 不改伤害数值、削韧、敌人血量
- 不改多人/联机，不绕过反作弊或 DRM
- 不修改现有 AutoPerfectDodge

## 2. 架构

独立 Mod 名：`WukongCombatKit`  
安装路径：

```
BlackMythWukong/b1/Binaries/Win64/CSharpLoader/Mods/WukongCombatKit/
  WukongCombatKit.dll
  config.json
  WukongCombatKit.log
```

入口类实现 `ICSharpMod`。`Init()` 读配置并注册 Harmony 补丁；`DeInit()` 卸载补丁。两个功能各自独立开关，互不依赖。

## 3. 组件

### 3.1 MyMod

职责：加载、卸载、读配置、注册可选调试快捷键。  
对外接口：`Init()`、`DeInit()`、`GetPlayerCharacter()`、`GetWorld()`。  
不直接改战斗逻辑。

### 3.2 DodgeCancel

职责：仅在轻攻/普通棍法连招中，放行空格触发的原版闪避，使闪避能取消当前普攻。  
对外接口：Harmony Prefix/Postfix，判断“当前是否轻攻连招”。  
依赖：玩家角色、当前技能/动作状态。  
不做：自动按闪避、改完美闪避窗口、取消技能/蓄力/棍势。

识别规则：

- 允许取消：轻攻连招、普通棍法普攻段
- 禁止取消：法术、变身、重击蓄力、释放棍势、身法技能、倒地/受击硬直、已在闪避中

空格仍走游戏原版闪避输入链。Mod 只放宽“普攻状态是否允许被闪避取消”，不伪造输入。

### 3.3 OmniHit

职责：玩家发起攻击判定时，把朝向限制改为以自身为原点的球形检测；距离默认几乎无限；每个候选敌人必须通过墙壁/地形射线才命中。  
对外接口：Harmony 补丁攻击扫描/命中检测入口。  
依赖：玩家位置、敌人列表、世界射线检测。  
不做：改伤害公式、锁血、补额外伤害事件、隔墙命中。

命中规则：

- 中心：玩家角色当前位置
- 方向：四面八方，不要求面向目标
- 距离：默认 `MaxAttackRange = 100000`（游戏单位，表现为几乎无限）
- 遮挡：玩家到敌人中心/胶囊体做射线；碰到静态地形/墙体则不命中
- 目标：敌对单位；不误伤自己、友方、场景物件（除非原版该次攻击本就会打到该类型）

### 3.4 Config

字段：

- `EnableDodgeCancel`：默认 true
- `EnableOmniHit`：默认 true
- `MaxAttackRange`：默认 100000
- `DebugLog`：默认 false

缺项用默认值。配置错误只记日志，不阻止加载。

### 3.5 Log

写入 `Mods/WukongCombatKit/WukongCombatKit.log`。调试项仅在 `DebugLog=true` 时输出。

## 4. 数据流

```
空格按下
  -> 游戏原版闪避输入
    -> DodgeCancel 读取当前动作
      -> 轻攻连招：允许取消，执行闪避
      -> 其他动作：保持原版，不取消

玩家攻击判定开始
  -> OmniHit 收集范围内敌人
    -> 对每个敌人做墙体/地形射线
      -> 无遮挡：纳入本次命中
      -> 有遮挡：跳过
    -> 命中结果交回原版伤害/削韧/特效流程
```

## 5. 错误处理

- 补丁注册失败：记 Error 日志，其余功能继续
- 找不到玩家、世界、动作状态：本次跳过
- DodgeCancel 与 OmniHit 各自 try/catch，一边失败不影响另一边
- 射线或敌人枚举异常：本次攻击回退到原版判定
- 不抛到游戏主循环

## 6. 实现约束

- 技术栈：C#、Harmony、B1CSharpLoader
- 目标运行时：游戏现有 Net 4.0 / Mono，禁止引入 `System.Private.CoreLib` 或 net10 程序集引用
- 源码编译若引用 GameDll，只作本地引用，不提交游戏程序集
- 优先复用已验证入口：`CheckSkillCanCast`、`TryPreciseDodge`、攻击扫描组件、玩家输入动作
- 若某入口签名随游戏更新变化：该功能降级关闭并写日志，不崩溃

## 7. 验证

必须同时满足：

1. 轻攻连招中按空格，普攻被打断并滚出普通闪避
2. 蓄力、释放棍势、法术、变身中按空格，不能被闪避打断
3. 背后/侧面无遮挡敌人能被本次攻击打中
4. 隔墙、隔山的敌人不能被打中
5. AutoPerfectDodge 仍按原逻辑工作
6. 关闭对应配置项后，该功能立即回到原版行为

## 8. 非目标

- 不做 UE4SS/Lua 方案
- 不做 pak 资源替换作为主方案
- 不做全图锁头、自动索敌、自动闪避
- 不做伤害倍率、无敌、无限棍势
